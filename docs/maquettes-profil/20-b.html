B · Grille et arbre : toutes les pages dans une barre latérale, chaque cube et chaque mélange à un clic

Le profil prend une barre latérale à lui, comme des réglages : ses six pages, et sous la page ouverte son arbre (Statistics : les cubes puis leurs mélanges avec Ao5 et nombre ; Training : les cubes puis leurs sets ; Awards : les catégories ; Analysis : les mélanges joués sur un cube connecté). La vue d'ensemble remplace les plaques par une grille cube × mélange : chaque case est un record, cliquer l'ouvre dans les Statistiques.

B1 · Overview

En haut, les chiffres de l'activité et ses 18 dernières semaines.
